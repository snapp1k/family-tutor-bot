# Семейный репетитор: запуск на Windows через уже оплаченную подписку ChatGPT

## Быстрый запуск: один BAT-файл

1. Скачай ZIP этого проекта, распакуй **полностью** в обычную папку, например `C:\FamilyTutor` (не запускай BAT прямо внутри ZIP).
2. Если бот уже работал раньше, **закрой его старое окно через Ctrl+C**. Чтобы сохранить задания и Telegram ID, скопируй в новую папку **только из своего старого проекта** файл `.env` и папку `data` (если они существуют). **Никому не отправляй** эти файлы: в них секреты и фото школьника. Новый архив их не содержит.
3. Уже установленный у тебя Codex CLI подойдёт. В PowerShell по желанию проверь `codex.cmd --version` и `codex.cmd login status`. Должно быть **Logged in using ChatGPT**. Не используй вход через API key.
4. Двойным щелчком запусти **`START_WINDOWS_CODEX.bat`**. На первом запуске он установит Python-зависимости, создаст `.env` сначала в безопасном демо-режиме (если его нет) и откроет Блокнот. После успешного теста режим автоматически переключится на Codex. Впиши туда свой `TELEGRAM_BOT_TOKEN` из BotFather и сохрани.
5. BAT проверит регистрацию Codex, отправит **один пробный запрос** репетитору, включит `BACKEND=codex` и запустит Telegram-бота. Первый запрос расходует часть включённого в подписку лимита Codex, но отдельная оплата API не требуется. При повторных запусках тестовый запрос не отправляется, если режим уже `codex`.
6. Не закрывай окно BAT, пока нужен бот. Для остановки — `Ctrl+C`.

### Что настроено

- Используется `codex exec` и **твой локальный вход ChatGPT**. Не нужен API-ключ `OPENAI_API_KEY`, карта или ещё одна подписка. Доступно в пределах текущих лимитов твоего плана.
- При запуске бот не передаёт дочернему процессу Telegram-токены, родительские коды или API-ключи. Но передаёт системные пути профиля Windows (`USERPROFILE`, `APPDATA` и т. д.) для поиска авторизации Codex.
- Команда `/pair tester КОД_ИЗ_ENV` привязывает тебя как тестировщика; команды `/mode parent` и `/mode student` переключают роль без переустановки.
- Родитель пишет `/new Задание`, прикладывает фото и `/publish`; ученик — `/tasks`, `/select НОМЕР`, текст/фото, `/done`; отец — `/report НОМЕР` и `/approve НОМЕР` или `/retry НОМЕР`.
- Фото и история сохраняются локально в `data/`. Никнейм можно сменить: права завязаны на **Telegram ID**.

### Как убедиться, что работает настоящая нейросеть

Останови бот, запусти **`TEST_CODEX_WINDOWS.bat`**. Он прогонит локальные тесты и один живой запрос к Codex (расходует подписочный лимит). В самом Telegram вместо ответа «Демонстрационный режим» бот должен объяснять тему конкретного задания и просить собственный следующий шаг.

### Типовые ошибки

| Ошибка | Что делать |
| --- | --- |
| `python`, `py` не найдены | Поставь Python 3.12+ с официального python.org; обязательно `Add Python to PATH`, затем новый терминал |
| `codex` не найден | Поставь Node.js LTS, затем `npm.cmd install -g @openai/codex@latest` в PowerShell, затем перезапусти терминал |
| `ChatGPT login was not detected` | Выполни `codex.cmd login` под **тем же пользователем Windows**, который запускает BAT. Выбери ChatGPT, не API key |
| `Codex CLI не выполнил запрос` | Проверь `codex.cmd login status`, лимиты своей подписки и доступ к сети. При необходимости `TEST_CODEX_WINDOWS.bat` |
| «Демонстрационный режим» | Убедись, что в `.env` стоит `BACKEND=codex`, перезапусти бот; проверь, не работает ли старый бот |
| `Conflict: terminated by other getUpdates request` | Только **один** процесс Telegram-бота может использовать этот BotFather токен. Закрой вторую копию на Windows или Ubuntu |
| Фото не распознано | Ученик может отправить JPG/PNG/WEBP в личный чат; проверь, что выбрано опубликованное задание |

### Безопасность и границы

Платформа Codex предназначена прежде всего для агентной разработки. Такое использование CLI как Telegram-репетитора — **экспериментальное**, не официальный серверный API. Оно может работать медленнее, поддержка может меняться и лимиты подписки конечны. Для постоянной работы с другими людьми необходимо учитывать условия использования подписки; не передавай никому свои учётные данные. Ни одна LLM не даёт стопроцентной защиты от выдачи ответа — проверку результата подтверждает взрослый.

**Не публикуй** `.env`, `data/`, `.codex/`, `auth.json` и скриншоты секретных кодов. Никаких паролей, токенов и кодов входа в этом проекте не требуется присылать в ChatGPT.

## Если BAT открывается и тут же закрывается (исправление 2026-11-23)

Используйте обновлённый `START_WINDOWS_CODEX.bat` **из полностью распакованного архива**. Теперь он запускает постоянное окно `cmd /K`: даже при ошибке окно останется открытым. Для обновления старой папки перенесите `START_WINDOWS_CODEX.bat`, `windows_launcher.py` и `tests/test_windows_diagnostics.py` вместе с файлом `WINDOWS_CODEX_RU.md`. Не заменяйте `.env` и `data` старого бота: это секреты и личная история.

1. Остановите **другой** запущенный экземпляр бота (включая Ubuntu VM) с тем же токеном.
2. Полностью распакуйте ZIP, запустите `START_WINDOWS_CODEX.bat` двойным нажатием. Не запускайте BAT из окна предварительного просмотра ZIP.
3. На первом запуске могут установиться Python-зависимости. Если потребуется, Блокнот откроет `.env` для ввода **только на вашем ПК** токена BotFather.
4. Когда видите `[TELEGRAM] Launching tutor with Codex`, не закрывайте окно — это запущенный бот. Если работа завершилась, смотрите текст выше и файл `data/logs/windows_startup.log`.
5. В терминале в папке проекта можно также выполнить `cmd /k START_WINDOWS_CODEX.bat`, чтобы видеть сообщения вручную.

**Если нужна помощь:** пришлите сообщение `[ERROR]` с экрана и статус этапов из `data/logs/windows_startup.log`. Не присылайте `.env`, Telegram-токен, коды привязки, авторизацию Codex, фотографии ребёнка или полные логи с личной перепиской.
