# Windows — подключение Family Tutor Bot к ChatGPT через Codex CLI

1. Скачай ZIP проекта, распакуй его полностью, например в папку C:\FamilyTutor.
2. Если уже использовал бот ранее, останови прежний процесс (Ctrl+C) и скопируй из старой папки в новую **только собственные** .env и data/. Это сохраняет токен, Telegram ID, задания и фото. Никому не отправляй эти файлы.
3. Убедись, что Codex CLI установлен и команда `codex.cmd login status` в PowerShell показывает **Logged in using ChatGPT**. При необходимости выполни `codex.cmd login`; выбери ChatGPT, не API key.
4. Запусти двойным щелчком **START_WINDOWS_CODEX.bat**.
5. На первом запуске будет создано Python-окружение и открыт файл .env. Заполни TELEGRAM_BOT_TOKEN (из BotFather), сохрани файл и вернись к окну BAT. Коды для привязки родителя, ученика и тестировщика создаются автоматически.
6. Установщик отправит один тестовый запрос к Codex, переключит BACKEND=codex и запустит Telegram. При следующих запусках тест не повторяется, если Codex уже выбран.
7. Для отдельной проверки после остановки бота — **TEST_CODEX_WINDOWS.bat** (локальные тесты + один запрос к модели).

## Что стоит знать

Codex CLI использует вход в существующий аккаунт ChatGPT, **не требует отдельного API-ключа или нового платежа**, однако расходует лимит Codex, доступный в подписке. Это экспериментальное использование CLI для семейного Telegram-приложения, не полноценный официальный API. Работу под вашей Windows нельзя проверить дистанционно без запуска у вас. Нельзя обещать полную защиту от списывания: родитель подтверждает задания сам.

Команды: тестировщик привязывается через `/pair tester СЕКРЕТНЫЙ_КОД`, затем `/mode parent` и `/mode student`. Отец: `/new Задание`, фото, `/publish`, `/report НОМЕР`, `/approve НОМЕР`. Ученик: `/tasks`, `/select НОМЕР`, вопросы или фото, `/done`.

## Частые ошибки

- Codex CLI отсутствует: установи Node.js LTS и затем `npm.cmd install -g @openai/codex@latest`; перезапусти терминал.
- Нет Python/py: установи Python 3.12+ с python.org, затем новый терминал.
- Не проходит вход: выполни `codex.cmd login` **под тем же Windows-пользователем**, который запускает BAT, и выбери ChatGPT.
- «Демонстрационный режим»: останови старого бота, проверь .env на BACKEND=codex и перезапусти.
- Ошибка Telegram Conflict 409: одну и ту же учётную запись бота нельзя одновременно запускать на Windows и Ubuntu.
- Ошибка лимита Codex: проверь оставшуюся квоту ChatGPT, не вводи API-ключ для обхода платы.

**Не публикуй** реальные .env, data/, .codex/ и auth.json. Токены, пароли и коды привязки в чат присылать не нужно.
